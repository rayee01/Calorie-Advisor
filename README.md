# Calorie Advisor

An AI-powered food calorie advisor created with a clean format to estimate calories and macronutrients from food images.

## Features

* Simple food image uploading (JPG, JPEG, PNG)
* Identifies food items and estimated portion sizes
* Calculates estimated calories per item
* Provides approximate total protein, carbohydrates, and fat
* Fast and clean Streamlit UI

## Technologies & Skills

* Python
* Streamlit
* Google GenAI (Gemini 3.6 Flash)
* Pillow (PIL)
* python-dotenv

## Analysis Options Included

* Food Name Identification
* Portion Size Estimation
* Calorie Counting
* Macronutrient Breakdown

## Purpose

The purpose of this repository is to provide a simple tool that estimates the nutritional value of meals from images, keeping in mind that exact portion sizes and ingredients cannot always be perfectly determined from an image.



This project is for personal and professional use.
